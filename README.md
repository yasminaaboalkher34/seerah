# سِيرَة (Seerah) - المنصة المتكاملة للموارد البشرية والمالية

صفحة هبوط حديثة باللغة العربية (RTL) مبنية وفق أحدث معايير الويب والتصميم، ومجهزة للرفع المباشر على **GitHub** و **GitHub Pages**.

---

## 🚀 كيفية الرفع على GitHub خطوة بخطوة:

إذا كنت تستخدم موجه الأوامر (Terminal / PowerShell)، افتح المجلد ونفّذ الأوامر التالية:

```bash
git init
git add .
git commit -m "Initial commit - Seerah Landing Page"
git branch -M main
git remote add origin https://github.com/USERNAME/REPO_NAME.git
git push -u origin main
```
*(استبدل `USERNAME` باسم حسابك و `REPO_NAME` باسم المستودع على جيتهاب)*

---

## 🌐 تفعيل GitHub Pages لعرض الموقع أونلاين مجاناً:

1. ادخل على مستودع المشروع في **GitHub**.
2. اذهب إلى **Settings** (الإعدادات).
3. من القائمة الجانبية اختر **Pages**.
4. تحت قسم **Build and deployment**:
   - **Source**: اختر `Deploy from a branch`.
   - **Branch**: اختر `main` واجعل المجلد `/ (root)`.
5. اضغط **Save**.

خلال دقيقة واحدة سيكون موقعك متاحاً ويعمل على الرابط المباشر!
ملف `.nojekyll` مضاف ومجهز مسبقاً لضمان تحميل كل ملفات التنسيق والأيقونات بدون أي مشاكل.
